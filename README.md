# 画笺

画笺是面向 SillyTavern 1.14.x–1.18.x 的 GPT / OpenAI-compatible 与 NovelAI 双引擎生图扩展。AI 回复完成后，它会识别 `<draw>...</draw>`，在消息原位置显示生图卡片，也可仅对本次会话中新完成的 AI 消息自动生图。

从 1.1.0 起，默认使用“免服务端直连”模式：只需在 SillyTavern 的扩展安装窗口粘贴仓库链接，不需要 Termux 命令，也不需要启用 Server Plugins。

## 一键安装

在 SillyTavern 的“安装扩展”中填写：

```text
https://github.com/phyllis-0612/st-image-atelier
```

安装完成后刷新页面或重启 SillyTavern。扩展菜单中会出现「✦ 画笺」，状态应显示「免服务端模式已就绪」。

也可以点击聊天输入框左下角的魔法棒按钮，在展开菜单中选择「画笺」快速打开。

## 首次配置

设置页顶部可以随时切换「GPT / OpenAI」与「NovelAI」。切换后只会使用当前引擎的配置，两套密钥和预设互不覆盖。

### GPT / OpenAI-compatible

1. 保持运行模式为「免服务端直连（推荐，一键安装）」。
2. 在「API 预设」旁点击「新建」，自定义名称；填写 Base URL 和 API Key。
3. 在「模型」一栏点击旁边的「拉取模型」，然后从下拉框选择生图模型。
4. 点击「保存预设」。以后可直接用顶部预设下拉框快速切换整组 URL、Key 与模型。
5. 可点击「测试模型接口」确认模型列表接口；生图接口会在实际生成时单独验证。
6. 修改「默认尺寸 / 质量 / 数量」后点击「保存生图参数」，保存后的值会用于下次生图。如果 `<draw>` 显式带有 `ratio` 或 `quality`，标签参数优先。
7. 让 AI 回复：

```xml
<draw ratio="portrait" quality="high" count="1">
雨夜霓虹街道中的电影感人像
</draw>
```

默认手动点击生成；自动生图默认关闭。

从 1.6.11 起，GPT / OpenAI 生图提示词上限为 32,000 个字符，直连、服务端模式及「调整后重绘」均支持；超限会在发送请求前提示，不会截断后发送。使用服务端模式时需同步更新可选 Server Plugin 至 1.3.6 并重启酒馆。NovelAI 正负面提示词仍各限 20,000 个字符；中转站可能有自己的更低上限。

### NovelAI

1. 切换到「NovelAI」。NAI 固定使用免服务端直连，不需要 Server Plugin。
2. 在「NAI 中转站 / 兼容站 URL」填写中转地址，在「中转站 Key / NAI Token」填写中转站分配的 Key。官方 NovelAI 与原生兼容站默认以 `Authorization: Bearer <Key>` 请求 `/ai/generate-image`；地址也可直接填写完整生图端点。Aurora 中转填写以 `/api` 或 `/api/v1` 结尾的地址即可，插件会自动归一化到实际的 `/api/generate-direct` 流式端点。
3. 选择 NAI 模型、尺寸、采样器、步数、Prompt Guidance、种子与负面提示词。
4. 在「画师串预设（每套独立正面 + 负面）」中新建并命名风格串；每套预设分别保存自己的正面和负面画师串。紧邻预设选择器的「预设分享（JSON）」可导出当前或全部非空预设，也可导入别人分享的 JSON；完全重复项会自动跳过，同名但内容不同的预设会自动改名。生成时正面按「该预设正面串 → 标签正文 → 模型质量标签」拼接，负面按「该预设负面串 → 可选的全局附加负面词」拼接，不会修改聊天原文。
5. 点击「保存 NovelAI 配置」。此后手动和自动生图都会使用当前 NAI 模型与画师串预设。

NAI 中转站 Key / NovelAI Token 与 GPT API Key 分开保存在当前酒馆账户存储中，不会写入扩展设置、聊天消息或图片元数据。中转站既可返回 NovelAI 原生 ZIP 图片包，也可返回常见 JSON/Base64 图片结构或 Aurora 的 NDJSON 流；插件会统一解析、补全相对图片地址，并逐张保存到酒馆图片目录。官方接口同样兼容：站点填写 `https://image.novelai.net` 即可。

NAI 中转站需要兼容 NovelAI 的原生生图请求体（`input`、`model`、`action`、`parameters`），并允许 SillyTavern 页面来源进行 CORS 跨域访问。若中转站只提供 OpenAI `/v1/images/generations` 格式，请改用「GPT / OpenAI」引擎；这种接口不是 NAI 原生协议，是否支持 NAI 专属采样参数取决于中转站。

## 主要能力

- 一条消息可含多个独立 `<draw>` 标签。
- 标签会在正文中的原位置直接替换成生图卡片；即使酒馆净化器移除了标签本身、只留下提示词，也会按提示词定位替换。正文完成后延迟追加的标签同样会实时识别。
- 同一标签可反复生成，卡片保留最近 8 张历史结果；后续新图超过上限时，最旧图片及其画廊记录会被永久删除。服务端模式需同步更新可选 Server Plugin 至 1.3.8。
- 生图失败或尚未生成的卡片可一键「删除」，连同消息里的 `<draw>` 标签和元数据一起清掉，不留痕迹。
- 可选开启「允许临时修改提示词后重绘」：从上一张图实际使用的基础提示词继续改，只作用于下一次生成，不修改聊天正文或原标签；NovelAI 可同时临时调整负面提示词。
- 自动生图使用固定 `auto:<tagId>`，刷新、切换聊天和重启不会重新提交；标签注入由 DOM 变化即时触发，低频扫描仅作兜底。
- URL 与 Base64 返回都会立即上传到当前 SillyTavern 用户的图片目录。
- 多 API 命名预设、独立密钥、模型下拉选择与快速切换。
- GPT / OpenAI-compatible 与 NovelAI 双引擎一键切换；NAI 支持独立站点、Token、模型和常用生成参数。
- 可命名、新建、删除、快速切换及通过 JSON 导入导出包含独立正面/负面内容的 NovelAI 画师串预设，并保留每张图实际使用的模型、画师预设与随机种子元数据。
- 画师串分享 JSON 只包含名称与正负面内容，不导出 API Key、NAI Token、内部 ID 或时间戳。
- 默认请求 `b64_json` 内嵌返回，不依赖浏览器二次下载图床 URL；可选开启「生成失败后智能重试」，遇到暂时性接口故障时最多自动重试 3 次，参数兼容回退也计入此上限。
- 生图失败会显示上游 HTTP 状态和经过脱敏的真实错误原因。
- 若上游内容审核拒绝提示词，会明确显示审核原因，不再混用参数不支持提示。
- 紧凑的五态消息卡片、分区设置页与双列响应式画廊。
- 已有图片重新生成时会立即切换到“正在重新生成”加载动画，完成后再展示新图。
- 内置方图、竖图和横图的常用尺寸（包括 `512x768`、`576x1024`、`1024x576` 等）；尺寸值会在请求前自动把 `×`、`X` 或 `*` 统一为接口要求的小写 `x`。
- 正文图片和画廊图片均可点击进入酒馆内的原图查看层；手机可直接长按保存，右上角固定关闭按钮、页面返回键和底部关闭按钮都能回到原聊天。
- 支持图片文件分享的系统会额外显示“分享 / 保存”按钮，不再把不稳定的自动文件下载作为移动端主流程。
- 时间倒序画廊支持持久收藏、提示词搜索、组合筛选、批量收藏/删除/下载与元数据真删；进入批量模式后可直接点缩略图或文字区选图。支持按保留天数或保留张数自动清理旧图，收藏图片不参与自动清理。画廊元数据独立保存在当前 ST 用户文件中，不会继续撑大 `settings.json`。
- 直连生成的任务详情也存放在独立的画廊元数据文件中；聊天楼层只保留提示词、状态及少量图片引用。设置页「界面与画廊」里的「瘦身当前聊天」可手动迁移旧楼层及滑动分支，完成后只保存一次聊天。按钮旁显示处理阶段与前后大小，完成或失败时弹出酒馆提示；控制台也会打印前后 tags 字节数。重复点击不会重复保存。旧图超过卡片历史上限的记录会留在画廊，迁移本身不会删除图片。
- 日间、夜间和跟随酒馆三种主题模式；表单输入区使用独立高对比前景色与背景色。
- 可选 Server Plugin 增强模式保留服务端密钥、进程锁和独立 JSON 元数据。

## 主题与画廊清理

设置页的「界面与画廊」区域可选择「跟随酒馆主题」「日间模式」或「夜间模式」。主题切换会立即保存并应用到设置面板、消息生图卡片、画廊和原图查看层。

画廊清理提供两条可独立启用的规则：

- 按时间：删除早于自定义天数的图片，例如清理 7 天前的图片；
- 按数量：只保留最新的自定义张数，例如仅保留近 200 张。

两条规则同时启用时采用“任一命中即清理”，并始终从最旧图片开始。保存规则时会先确认并立即检查一次；之后在扩展启动、成功生成图片、打开画廊以及页面保持开启期间的每小时维护中自动检查。清理只处理画笺自己登记的本地图片，不会扫描或删除酒馆及其他扩展的图片。删除不可撤销，失败的文件会保留记录并在下次检查时重试。

收藏图片会同时排除在按时间与按数量清理之外；仍可手动删除，但会再次明确确认。画廊的搜索与筛选读取全部轻量元数据，图片本身仍只渲染当前页。桌面端可批量发起下载；移动浏览器常会阻止多文件下载，此时插件会保留选择并提示逐张打开原图后长按保存。

## 卡片历史翻页

从 1.6.10 起，同一正文卡片有两张以上可用图片时，会显示「上一张 / 下一张」和「当前张数 / 总张数」。按标签保存的历史顺序翻页，到第一张和最后一张时禁用对应按钮；只有一张时不显示翻页控件。

翻页时图片、尺寸、API 预设名、画质、模型和提示词同步切换，「查看 / 保存」和「调整后重绘」对应当前查看的图片。浏览历史只影响当前卡片，不修改已保存的最新图片标记，同层其他卡片独立翻页。

默认跟随最新回图。手动翻看旧图时，新回图只增加历史张数，不打断当前浏览；翻回最新一张后恢复跟随。正文重建时会保留同一卡片的当前选择，整页刷新后默认显示最新图。被删除或清理的图片不会参与翻页；当前选中图被删时回到最新可用图。

## 图片信息布局

从 1.6.12 起，正文卡片的「已完成」后显示当前图片的用时，例如「用时 1分23秒」。从本次任务开始计时，到该图片保存完成为止，包含上游等待、重试、下载和保存；并行任务各自计时，翻页同步切换。新图独立保存用时，清理旧任务记录后仍可查看；旧图有对应任务时间时可补算，记录不足时不显示。服务端模式需同步更新可选 Server Plugin 至 1.3.7 才会为新图独立保存用时。

从 1.6.9 起，正文卡片的尺寸信息移到图片下方「历史 × 张」旁边，不再覆盖画面。下方紧凑信息栏显示 API 预设名、画质、模型；窄卡片会自动换行，长名称省略显示，并保留完整标题。

画廊缩略图下方原提示词预览改为 API 预设名和画质；模型、时间继续显示。点开原图仍可查看完整提示词，提示词搜索也保留。

新图片独立保存实际请求的尺寸和画质快照：不发送或兼容回退移除质量参数时显示「未发送」，缺少历史画质记录的旧图显示「未记录」，NovelAI 无此质量参数则显示「不适用」。切换当前预设不会改写旧图信息。服务端模式需同步更新可选 Server Plugin 至 1.3.5 才会为新图保存这些参数。

## 备用预设自动并行生成

从 1.6.8 起，设置中可以开启「备用预设自动并行生成」，选择另一个已保存的 API 预设，并填写「备用生成等待时长（秒）」。默认关闭，等待时长默认 180 秒，可设为 1–86400 秒；仅支持 GPT / OpenAI-compatible 免服务端直连，NovelAI 和 Server Plugin 模式不会触发。

主请求超过指定时长仍在等待上游时，自动使用备用预设的地址、Key、模型和请求配置，再发送一次相同提示词和标签参数，并弹出酒馆提示。原请求继续运行，两边回图都会保存；当前主预设不会被切换。每个主请求最多触发一次备用，备用请求不会继续触发备用。运行中的主任务使用启动时的备用预设选择和等待时长；关闭开关可阻止尚未启动的备用。

启用备用功能的主请求和自动备用请求会继续等图，不因本地等待超时而中断，即使「超时后继续等待图片」关闭。已完成、取消、进入下载或保存阶段的主请求不再启动备用。备用预设被删除或缺少地址、模型、Key 时，会提醒并跳过。并行生图属于独立的上游请求，会产生额外费用；页面关闭或上游自身断开仍可能结束请求。

## 慢上游与并行重 roll

从 1.6.7 起，「超时后继续等待图片」默认开启，包括原来已保存 180 秒超时的预设。达到「等待提醒 / 超时（秒）」时只更新等待提示，原生图请求继续运行，不会仅因为等待太久而中断或自动重发。GPT、NovelAI 直连与可选服务端 GPT 均支持；模型拉取和图片下载仍保留各自的超时。关闭此开关可恢复原来的硬超时，等待提醒 / 超时设置最多支持 3600 秒。

生成中的卡片提供「并行重 roll」和「换 Key / 预设」。先在设置里保存新 Key 或切换 API 预设，再点「并行重 roll」：新请求使用启动时的 Key、模型和参数，旧请求继续使用原来的快照。每个请求都有独立编号和取消按钮；取消一个不影响其他请求。自动生图仍按原队列执行，同一自动任务不会重复发起。

并行请求谁先返回就先显示；后返回的图片也会保存到同一个标签的历史和画廊。生成记录按发起顺序保留，旧请求的等待提示不会覆盖新请求的状态。已有结果显示时，其他仍在生成的任务会单独列出。

直连任务依赖当前酒馆页面和网络连接持续存在。刷新、关闭页面、浏览器终止连接或上游本身断开请求后，插件无法从普通同步生图接口追回迟到图片；本功能不会恢复已经被旧版 180 秒超时断开的请求。服务端模式能在关闭页面后继续执行，但服务本身重启仍会中断任务。上游明确返回错误时，仍按「智能重试」设置处理。

## 生图失败提醒、临时重绘与智能重试

生图失败会使用酒馆原生横幅通知，阅读正文时也能立即知道。自动重试期间显示当前轮次（1/3、2/3、3/3），达到上限后通知已停止，并保留消息末尾的手动重试按钮；关闭自动重试时仍会提醒首次失败。直连 GPT、NovelAI 和可选服务端 GPT 模式均支持。

「允许临时修改提示词后重绘」和「生成失败后智能重试」均默认关闭，可在插件设置中独立开启。前者不会保存未提交的草稿，也不会改写 `<draw>`。后者在首次失败后最多自动重试 3 次，也就是每次任务最多向上游发送 4 次生图请求；参数兼容回退与网络、超时、429、5xx 等暂时性故障共用此上限。参数回退只移除错误明确点名的 `response_format`、`size`、`quality` 或 `n`，后续请求继续使用回退后的参数。暂时性故障依次等待 1.5、3、6 秒；成功或取消后立即停止。审核、密钥/权限、余额/配额、未知业务错误以及出图后的下载或本地保存失败不会再次发起生图。

## 免服务端模式的网络要求

浏览器会直接请求中转站，因此中转站必须允许 SillyTavern 页面来源进行 CORS 跨域访问。若模型接口测试提示“浏览器无法连接”，请检查：

- Base URL 是否正确；
- 手机能否访问该地址；
- 中转站是否返回 `Access-Control-Allow-Origin`；
- HTTPS 页面是否请求了被浏览器拦截的 HTTP 地址。

API Key 保存在当前 SillyTavern 账户的前端账户存储中，不写入聊天消息、图片元数据、日志或 Git 仓库。由于请求发生在浏览器中，其他同源前端扩展理论上仍可访问请求数据；高安全需求请使用可选 Server Plugin 模式。

如果生成接口能连接，但返回的临时图片 URL 被 CORS 阻止，请在高级设置把「图片返回格式」设为 `b64_json`（新安装默认如此），让兼容中转站直接返回 Base64。

## 可选增强模式

仓库仍包含 `server-plugin/`。它适用于不支持 CORS 的中转站，或必须把完整 Key 与生成幂等锁留在服务端的部署。安装方法见 [docs/INSTALLATION.md](docs/INSTALLATION.md)。普通用户无需安装。
