# 人工验收计划

## 准备

- [ ] ST 版本在 1.14.x–1.18.x
- [ ] `enableServerPlugins: true`
- [ ] 工具窗口显示「服务端已连接」
- [ ] 使用 mock 或明确可控的测试中转站

## 标签与恢复

- [ ] AI 消息单标签完成后出现卡片，流式中不出现/不调用
- [ ] 一条消息两个标签出现两个独立卡片
- [ ] 用户消息、system、reasoning 中的标签不处理
- [ ] 未闭合和嵌套标签不处理
- [ ] 刷新后卡片恢复且 upstream 计数不增加
- [ ] 切换聊天、关闭重开后恢复且 upstream 计数不增加
- [ ] 编辑消息：未变标签保留历史，变更标签获得空白新卡片

## 手动与自动生图

- [ ] 手动点击一次只发一个上游请求
- [ ] 快速双击仍只发一个请求
- [ ] 同标签重新生成新增历史结果
- [ ] 自动开关关闭时不自动生成
- [ ] 开启后仅新完成 AI 消息自动生成
- [ ] 同消息四个标签时仅前三个自动，第四个保留手动按钮
- [ ] 自动失败不重试
- [ ] 删除自动图片后不自动补图

## 配置与安全

- [ ] Base URL 为 `/v1` 时预览不出现 `/v1/v1`
- [ ] 模型拉取成功；失败后旧缓存仍可选
- [ ] 手动模型可保存
- [ ] Key 留空保留，清除按钮才删除
- [ ] 浏览器响应和日志看不到完整 Key
- [ ] HTTP 默认拒绝，开启后显示警告

## 画廊

- [ ] 结果按时间倒序显示
- [ ] 查看原图和下载可用
- [ ] 删除前确认
- [ ] 删除后文件消失、刷新不复活
- [ ] 最新图删除后卡片回退到次新图

## 视觉

- [ ] 浅色主题文字、边框、按钮可辨识
- [ ] 深色主题文字、边框、按钮可辨识
- [ ] 390×844 视口不横向溢出
- [ ] 主要触控区域至少 44×44 px
- [ ] Esc、遮罩、关闭按钮均能关闭工具窗口
- [ ] `prefers-reduced-motion` 下无持续动画
