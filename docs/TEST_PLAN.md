# 人工验收计划

## 准备

- [ ] ST 版本在 1.14.x–1.18.x
- [ ] 通过仓库链接安装，无 Termux 操作
- [ ] 工具窗口显示「免服务端模式已就绪」
- [ ] 使用支持 CORS 的测试中转站

## 安装与配置

- [ ] 未启用 Server Plugins 也能打开扩展
- [ ] Base URL 为 `/v1` 时预览不出现 `/v1/v1`
- [ ] 模型拉取成功；失败后仍可手动填写模型
- [ ] 连接测试不会触发生图费用
- [ ] Key 留空保留，清除按钮才删除
- [ ] 聊天 JSON、图片 metadata 和控制台不含完整 Key
- [ ] CORS 失败时显示明确中文提示
- [ ] HTTP 默认拒绝，开启时有安全警告

## 标签与恢复

- [ ] AI 消息单标签完成后出现卡片，流式中不调用
- [ ] 一条消息两个标签出现两个独立卡片
- [ ] 用户消息、system、reasoning 标签不处理
- [ ] 未闭合和嵌套标签不处理
- [ ] 刷新、切换聊天、关闭重开后恢复且不增加上游调用
- [ ] 编辑消息：未变标签保留历史，变更标签获得新卡片

## 手动与自动生图

- [ ] 手动点击一次只发一个上游请求
- [ ] 快速双击仍只发一个请求
- [ ] 同标签重新生成新增历史结果
- [ ] URL 与 Base64 返回都保存到酒馆图片目录
- [ ] 开启自动后仅新完成 AI 消息触发
- [ ] 同消息四个标签时仅前三个自动
- [ ] 自动失败不重试
- [ ] 删除自动图片后不自动补图

## 画廊

- [ ] 结果按时间倒序显示
- [ ] 查看和下载原图可用
- [ ] 删除前确认
- [ ] 删除后底层文件消失且刷新不复活
- [ ] 最新图删除后卡片回退到次新图

## 视觉

- [ ] 浅色和深色主题均清晰
- [ ] 390×844 视口不横向溢出
- [ ] 主要触控区域至少 44×44 px
- [ ] Esc、遮罩、关闭按钮均能关闭窗口
- [ ] `prefers-reduced-motion` 下无持续动画

## 可选增强模式

- [ ] 显式安装 Server Plugin 后能切换模式
- [ ] 服务端未安装时选择增强模式会显示明确错误
- [ ] 切回免服务端模式后无需重启即可继续配置
